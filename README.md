A beginner project to understand ASP.NET CORE MVC Architecture (Model, View, Controller) + NHibernate ORM.
Also uses SQL Express as the database (Managed using Microsoft SQL Server Management Studio).
It features CRUD actions:
- Add Product Category, Supplier
- Adding Product or Digital Product
- Editing the values of the Product e.g name, image. 
- Deleting Product Category, Supplier, Product, Digital Product

Some other Core Features:
- Point of Sale with the option to choose the quantity of the product , and can add more than one product type (e.g choosing books and pens) in single transaction.

Functional Feature:
- Low stock alert text when the stock is below the threshold
- Total revenue
